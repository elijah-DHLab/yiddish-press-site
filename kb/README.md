# מאגר הידע (Knowledge Base) של העיתונות היידית

המאגר מחליף את הרשימות החופשיות שבגיליון (אנשים, מקומות, ארגונים, קבוצות, נושאים) בישויות מנוהלות עם מזהה קבוע,
מקושרות לוויקידאטה, ומחוברות זו לזו בקשרים (אונטולוגיה קטנה).

## הקבצים (`kb/`)
| קובץ | תוכן |
|---|---|
| `entities.json` | כל הישויות. שדות: `id` (`pl:fez`, `ppl:abd-al-hafid`, `top:french-protectorate-morocco`, `ev:treaty-of-fez`), `type`, `he` (שם תצוגה), `en`, `desc`, `kind`, `role`, `parent` / `broader` / `country`, `qid` (ויקידאטה), `aliases` (הכתיבים בגיליון) |
| `surface_forms.json` | `map`: כתיב בגיליון ← מזהי ישויות, לפי סוג העמודה. `contextual`: כתיבים עמומים ("סולטאן", "הפרלמנט") ← ישות לכל כתבה בנפרד. `dropped`: כתיבים שאינם ישות |
| `relations.json` | `[נושא, יחס, מושא, מקור]`. מקור `kb` = נקבע במאגר, `wikidata` = נגזר מוויקידאטה (רק בין ישויות שבמאגר) |
| `wikidata.json` | ההעשרה: שמות בעברית/יידיש/אנגלית, תיאור, קואורדינטות, תאריכים, תמונה, ערכי ויקיפדיה, טענות גולמיות |
| `redirects.json` | מזהים שאוחדו (שני מזהים שהתבררו כאותו פריט ויקידאטה) |
| `work/` | תוצרי ביניים: האצוות, פלטי האיחוד, אוצר המילים (`vocab.json`), מיפוי הנושאים (`topicmap_*.json`), מועמדי ויקידאטה |

### סוגי ישויות
`ppl` אנשים · `pl` מקומות · `org` ארגונים ומוסדות · `grp` קבוצות אוכלוסייה · `top` נושאים (אוצר מילים מבוקר) · `ev` אירועים מתוארכים

### יחסים
| יחס | בין | דוגמה |
|---|---|---|
| `located_in` | מקום ← מקום | פאס ← מרוקו |
| `broader` | נושא ← נושא, אירוע ← נושא, קבוצה ← קבוצה | הסכם פאס ← הפרוטקטורט הצרפתי ← שאלת מרוקו |
| `part_of` | ארגון ← ארגון, אירוע ← אירוע | |
| `country` | אדם/ארגון ← מדינה | ז'ול קמבון ← צרפת |
| `location`, `participant` | אירוע ← מקום/ישות | הסכם פאס: מקום פאס; משתתפות צרפת ומרוקו |
| `member_of` | אדם ← ארגון (מוויקידאטה) | |
| `related` | נושא ← ישויות | שאלת מרוקו ~ צרפת, גרמניה, ספרד |

באתר, ישות "כוללת" את כל מה שמתחתיה דרך `located_in` / `broader` / `part_of`:
חיפוש "מרוקו" מוצא גם כתבות על פאס, וחיפוש "שאלת מרוקו" מוצא גם את הסכם פאס ואת משבר אגאדיר.

## איך המאגר נבנה (אוטומטית)
```
python kb/scripts/01_extract.py            # חילוץ כל הכתיבים + הקשר הכתבות → kb/work/
   (איחוד ישויות לכל אצווה בעזרת מודל שפה → kb/work/ent_<type>_<n>.json, בדיקה: kb/scripts/validate.py)
   (אוצר מילים לנושאים ולאירועים → kb/work/vocab.json; מיפוי כל ניסוח נושא → kb/work/topicmap_<n>.json)
python kb/scripts/wd.py candidates kb/work/ent_*.json   # מועמדי ויקידאטה מחיפוש אמיתי (לא מהזיכרון)
   (בחירת המועמד הנכון לכל ישות לפי שם, תאריכים וסוג → שדה qid)
python kb/scripts/02_merge.py              # מיזוג → entities.json, surface_forms.json, redirects.json
python kb/scripts/03_enrich.py             # ויקידאטה → wikidata.json, relations.json
python build_data.py analysis_an-002.xlsx  # data.json לאתר
```

## תחזוקה
- **תיקון שיוך**: לערוך את `kb/work/ent_*.json` (או `vocab.json` / `topicmap_*.json`) ולהריץ שוב 02 → 03 → build_data.
  דוגמה: להעביר כתיב לישות אחרת = להעביר אותו בין רשימות `keys`.
- **שורות חדשות בגיליון**: `build_data.py` מדפיס כתיבים שאינם מוכרים למאגר, והם מוצגים באתר במסגרת מקווקוות.
  כדי לשייך אותם: להריץ שוב את 01 ולעבד רק את המפתחות החדשים (או להוסיף אותם ידנית ל-`keys` של ישות קיימת).
- **כלי עזר**: `python kb/scripts/ctx.py ppl "סולטאן"` מציג את הכתבות של כתיב מסוים; `python kb/scripts/wd.py search "Jules Cambon"`
  מחפש בוויקידאטה.
