# העיתונות היידית 1905–1917 · מעבדת אליהו, אוניברסיטת חיפה

אתר סטטי (ללא שרת) לחיפוש, ציר זמן והשוואה בין עיתונים ביידיש.

## העלאה ל-GitHub Pages
1. צרו ריפוזיטורי חדש והעלו אליו את **כל** תוכן התיקייה (index.html, css/, js/, logo.svg, data.json, ocr.json).
2. Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `(root)`.
3. האתר יעלה בכתובת `https://<user>.github.io/<repo>/`.

פתיחה ישירה של index.html מהמחשב (file://) לא תטען נתונים. להרצה מקומית: `python -m http.server` ואז http://localhost:8000.

## עדכון הנתונים כשהגיליון גדל
1. הורידו את הגיליון כ-xlsx או csv (אותן עמודות כמו היום).
2. `pip install openpyxl`
3. `python build_data.py analysis_an-002.xlsx imgmap.json`
4. העלו את `data.json` ו-`ocr.json` החדשים.

`imgmap.json` ממפה מזהה כתבה ← מזהי קבצי תמונה בגוגל דרייב (נבנה מהתיקייה המשותפת; כתבה ללא רשומה תציג רק קישור לספרייה הלאומית).
כדי שהתמונות יוצגו, קבצי הכונן צריכים להיות משותפים ל"כל מי שיש לו קישור".

## הגדרות לעריכה
- `js/util.js`: שמות וצבעי העיתונים (`H.PAPERS`), אירועי רקע (`H.EVENTS`).
- `build_data.py`: כללי נושאי-העל (`THEMES`), מופיעים גם בלשונית "על הנתונים".
- `index.html`: כותרת האתר.

## הערות מתודולוגיות
- מונחי האיסוף שונים בין העיתונים וטווחי התאריכים שונים, ולכן יש להשוות מגמות והרכב ולא נפחים.
- נושאי-העל ו"הקשר יהודי" הם תיוג אוטומטי לפי מילות מפתח.
